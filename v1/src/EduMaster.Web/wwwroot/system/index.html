시스템 설명

교사가 제공한 문제와 풀이를 분석해 단계별 연습 문제와 쌍둥이 문제를 만들고, 검토한 피드백을 다음 유사 문제에 참고하는 현재 시스템을 설명합니다.

문제 만들어 보기피드백 남기기
전체 흐름사용 모델피드백과 RAG검증보관과 한계
01 / 생성

문제는 이렇게 만들어집니다

1

문제와 풀이 입력

문제 이미지는 필수입니다. 풀이 이미지가 있다면 함께 넣고, 없으면 선택한 모델이 풀이 초안을 만듭니다. 한 이미지에 문제와 풀이가 모두 있으면 같은 이미지를 두 역할에 넣을 수 있습니다.

2

읽고 단계 정리

이미지의 글자·표·그림을 분석해 문제와 풀이를 구분합니다. 제공된 풀이의 보조 문자·치환·판단 순서를 보존하고 코드 계산은 정답 대조에 사용합니다. 해설 이미지가 있다면 교사가 분석된 풀이를 원본과 대조하고 확인해야 다음 단계로 갑니다. 풀이가 없다면 STEP 초안을 만듭니다.

3

단계별 문제 생성

STEP 1부터 앞 단계를 누적해 연습 문제를 만듭니다. 최종 쌍둥이 문제는 ‘통합 변형’과 ‘단순 숫자 변형’ 중 선택합니다. 통합 변형은 앞서 만들어 검사를 통과한 문제들의 조건·질문 아이디어를 참고해 모든 풀이 로직이 필요한 새 문제를 설계합니다.

4

검사하고 선택해 저장

코드 계산과 AI 검토로 조건·수치·정답·해설·그림 관계를 검사합니다. 완성된 세트에서 ‘학습 데이터 추가’를 눌러야 학습·피드백 목록에 나타납니다. ‘PDF 저장’은 별도 보고서를 저장하고 내려받으며 학습 데이터로 자동 추가하지 않습니다.

원본 문제의 답을 독립 계산기로 확인할 수 없는 유형은 ‘교사 검토 필요’로 표시하고 생성을 진행합니다. 코드 검산에서 명확한 오류가 확인된 경우에는 생성을 차단합니다.

02 / 모델

현재 사용하는 모델과 역할

DeepSeek V4 Flash

외부 API

서버에 설정된 deepseek-flash 모델입니다. 이미지 분석, 풀이·변형 문제 생성, 별도 문항 검토에 사용합니다. 선택해서 호출하며 API 사용량이 발생합니다.

현재 연결 설정 확인 중…

Gemma 4 12B

로컬 모델

PC에서 실행하는 이미지 지원 모델입니다. 선택하면 생성과 검토에 사용합니다. PC와 모델 서버가 연결돼 있을 때만 이용할 수 있습니다. 외부 모델 API 비용은 없지만 로컬 실행 시간이 듭니다.

현재 PC 연결 확인 중…

독립 계산 코드

모델 아님

지원하는 화학 문항 유형에서는 별도 계산기로 원본 답과 생성 답을 확인합니다. 모델의 자신감이나 피드백 승인만으로 정답을 통과시키지 않습니다. 유형별 계산기가 없는 문제는 검증 불가로 중단될 수 있습니다.

화면에서 선택한 생성 모델이 기준입니다. 문항 검토도 기본적으로 같은 공급자의 모델을 사용합니다. Gemma 이미지 판독이 실패하고 DeepSeek이 설정돼 있으면 이미지 분석만 DeepSeek으로 자동 보정될 수 있으며, 생성 모델 선택 자체는 바뀌지 않습니다.

03 / 피드백

지적한 오류는 다음 생성에 어떻게 반영되나요?

01학습 세트 추가

생성 결과에서 ‘학습 데이터 추가’를 누른 뒤 피드백 페이지에서 원본과 STEP별 문제·해설을 엽니다.

02오류와 수정 방향 기록

조건·정답·해설·그림·표현 중 무엇이 잘못됐고 어떻게 고쳐야 하는지 적습니다. 이때는 승인 대기 상태입니다.

03사람이 반영 승인

내용을 검토해 ‘반영 승인’을 누른 피드백만 재사용합니다. ‘반영 제외’한 내용과 승인 대기 내용은 검색 결과에서 빠집니다. 승인된 학습 내용 보기에서 현재 반영된 내용을 확인할 수 있습니다.

04다음 유사 문제에 참고

새 문제의 본문과 승인 피드백이 달린 과거 문제의 단어를 비교해 유사한 사례를 찾습니다. 해당 오류와 수정 원칙을 모델 입력에 넣고 새 조건으로 다시 검산합니다.

예시

피드백: “산성으로 가정한 풀이가 음이온/양이온 비율 조건과 모순된다. 전하 균형으로 산성 경우를 배제하라.”

다음 생성: 유사한 산·염기 문항이면 이 수정 원칙을 참고합니다. 이전 문제의 수치나 정답을 그대로 복사하지 않고 새 문항의 조건으로 계산합니다.

지금의 RAG·생성 지침

피드백 페이지의 해야 할 것·하지 말아야 할 것은 저장 후 모든 다음 생성 요청에 공통 적용합니다. 문항별 JSON 기록에서는 승인된 피드백을 검색합니다. 유사 문항 상위 3개의 피드백과 승인된 풀이 방식 선호 최신 3개를 참고하며 이전 수치·정답은 복사하지 않습니다. DeepSeek과 Gemma가 같은 저장소를 사용합니다.

아직 하지 않는 것

모델 가중치를 재학습하거나 파인튜닝하지 않습니다. 벡터 DB·임베딩 검색도 아직 없습니다. 승인한 피드백이 과거 결과를 자동 수정하지는 않으며, 관련 없는 문제에는 적용되지 않습니다.

풀이 방식·선생님 선호도 문제별 피드백으로 기록하고 승인할 수 있습니다. 유사 문항에서 원하는 문자 도입이나 간결한 풀이 전략을 참고합니다. 승인된 참고 내용이 바뀌면 생성 요청의 식별값도 바뀌어 이전 결과를 그대로 재사용하지 않습니다.

04 / 품질 관리

무엇을 검사하고, 무엇을 보증하지 못하나요?

생성 전

문제와 풀이의 일치 여부, 지원 유형의 원본 정답, 풀이 STEP 수와 입력 조건을 확인합니다. 독립 계산기 미지원 유형은 교사 검토 대상으로 표시합니다.

생성 후

조건 성립, 수치·단위·정답, 보기의 유일성, 표와 해설의 수치, O/X와 정답, STEP 사용 범위, 그림과 본문의 관계를 코드와 AI로 확인합니다. 오류가 발견되면 같은 단계를 최대 3회 재작성합니다.

화면과 PDF

브라우저가 만든 문제 이미지의 PNG 대조 검사를 별도로 진행합니다. 문항의 수학·과학적 타당성과 화면 표현은 다른 검사이며, 한쪽 통과가 다른 쪽 통과를 뜻하지 않습니다.

AI 검토와 현재 유형별 계산기는 모든 문항의 정답을 보증하지 않습니다. 독립 계산기가 없는 유형은 ‘교사 검토 필요’로 표시됩니다. 코드 검사에서 명확한 모순이 발견되면 결과를 차단하며, 최종 사용 전 교사의 검토가 필요합니다.

05 / 보관

자료는 어디에 남나요?

자료현재 보관 방식알아둘 점
생성 작업 조회서버 작업 캐시약 2시간 뒤 정리됩니다.
문제와 피드백서버의 별도 학습 보관함직접 추가한 세트만 학습 목록과 피드백 검색에 사용됩니다. 승인된 피드백만 다음 생성에 참고합니다.
전체 생성 지침서버의 설정 파일저장 후 새로 시작하는 모든 문제 생성에 적용됩니다.
입력 원본 이미지임시 이미지 보관 및 학습 보관함생성 중에는 약 2시간 보관합니다. 보관 시간 안에 ‘학습 데이터 추가’를 누르면 원본 이미지를 학습 보관함에 복사합니다.
PDF 저장서버에서 만든 뒤 기기로 다운로드저장된 PDF 목록과 다시 보기 화면은 제공하지 않습니다. PDF 저장은 학습 데이터 추가와 별개입니다.

이 페이지는 현재 구현을 설명합니다. 의미 기반 벡터 검색, 정답 교정 자동 적용, 모델 파인튜닝은 향후 개선 대상이며 현재 동작으로 표시하지 않습니다.

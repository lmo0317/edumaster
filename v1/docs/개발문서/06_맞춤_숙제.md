# 06 학생마다 다른 보충 숙제 만들기

상태: 미착수 · 이전: [05 학생 답을 직접 넣고 채점하는 MVP](05_수동_채점_MVP.md) · 다음: [07 OMR 한 장으로 답안 입력하기](07_OMR_입력.md)

## 이번 단계에서 끝낼 것

같은 반의 공통 문제는 같고 보충 문제는 학생마다 다른 다음 주 학습지를 만듭니다. 복잡한 점수 체계보다 눈에 보이는 선택 규칙 하나로 시작합니다.

```text
민수 계산 오답 → 공통 3개 + 계산 보충 2개
지우 보기 오답 → 공통 3개 + 판단 보충 2개
→ 선택 이유 → 교사 확인 → 학생별 PDF
```

## 시작 조건과 범위

- 05의 확정 답안과 문제의 연습 개념·풀이 단계 태그가 있어야 합니다. 각 항목의 승인 문제를 충분히 준비합니다.
- 학생 2명·연습 항목 2개·총 5문제 중 공통 3개와 학생별 2개로 시연합니다. 100문제·70/30은 이후 조절할 설정입니다.
- 객관식 정답 번호 하나로 틀린 이유를 확정하지 않습니다. 오답 사실과 연습 추천을 화면에서 구분합니다.

## 최소 구현

- [ ] **S06-01 보충 대상** — 확정 오답을 문제의 개념·풀이 단계와 연결하고 연습 후보로 표시합니다. 미제출은 약점 증거가 아닙니다.
- [ ] **S06-02 선택 규칙 하나** — 최근 오답 항목을 우선하고 같은 조건이면 고정 순서로 고릅니다. 이해 수준을 확정한 숙련도 점수로 표시하지 않습니다.
- [ ] **S06-03 공통·보충 편성** — 승인·권리 확인·미폐기 문제로 구성하고 공통·개인 문항 중복과 최근 동일 문제 반복을 검사합니다.
- [ ] **S06-04 부족 안내** — 조건에 맞는 문제 수가 부족하면 이유와 수량을 안내합니다. 미승인·임의 중복·몰래 줄인 수량으로 성공 처리하지 않습니다.
- [ ] **S06-05 교사 확인** — 배정 이유와 근거 답안을 보여 주고 교사가 교체·고정합니다. 학생 간 근거가 섞이지 않습니다.
- [ ] **S06-06 학생별 출력** — 04의 학습지 고정·PDF를 재사용하며 학생마다 실제 문항 순서·정답표를 유지합니다.
- [ ] **S06-07 정정과 추천** — 05에서 답을 정정하면 추천을 재계산합니다. 확정 다음 주 학습지는 덮어쓰지 않고 교사가 새 버전으로 확정합니다.

## 간단 테스트

| 직접 해 볼 일 | 기대 결과 |
|---|---|
| 서로 다른 항목 오답으로 편성 | 공통 문항은 같고 보충 문항·사유는 다름 |
| 필요한 승인 문제 부족 | 부족 수·항목 표시, 확정 불가 |
| 오답 정정 뒤 다시 추천 | 추천 갱신, 확정 학습지 유지 |
| 미제출 학생에게 추천 | 근거 없이 모든 항목을 약점 확정하지 않음 |
| 학생별 PDF와 직접 채점 확인 | 각 학생의 실제 순서·정답표로 채점 |

앞 단계의 대표 흐름도 한 번 실행합니다. 아래 완료 기록에 실제 테스트 결과를 남깁니다.

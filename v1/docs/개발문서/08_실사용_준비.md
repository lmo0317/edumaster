# 08 한 반에서 쓰기 위한 준비 끝내기

상태: 미착수 · 이전: [07 OMR 한 장으로 답안 입력하기](07_OMR_입력.md) · 다음: [09 선택 확장](09_선택_확장.md)

## 이번 단계에서 끝낼 것

새 기능보다 실사용 범위·권한·비용·복구를 먼저 확인합니다. 준비 점검을 하나의 완료 단위로 끝내고, 그 뒤 한 반 4주 파일럿을 따로 진행합니다.

```text
운영 범위·담당자 → 권한·품질·예산·복구 점검 → 한 반 4주 운영 → 오류 수정 → 지원 범위별 출시
```

## 시작 조건과 범위

- 01~07의 최소 범위와 필요한 보완의 실제 완료 기록이 있어야 합니다. 학생 수·분량·지원 유형·OMR 조건·배포 방식·품질 기준을 정합니다.
- 외부 접속이나 실제 학생 데이터를 앞 단계에서 쓰려면 아래 관련 준비를 앞당겨 적용합니다. 단계 번호가 뒤라고 보호까지 미루지 않습니다.
- 미완료 사진·자동 판독 기능은 사용 범위에서 제외하고 양호 스캔·사람 확인 등 운영 제한을 화면과 안내에 표시합니다.

## 최소 구현

- [ ] **S08-01 계정과 권한** — Windows 사용자·데이터 폴더 접근 권한과 앱 서비스·WebView2·워커의 접근 경계를 확인합니다. 키 보호를 전체 DB 암호화로 간주하지 않습니다. 공유·서버·다기관 도입 시에는 로그인·서버 권한·기관별 격리를 별도 적용하고 직접 접근도 검사합니다.
- [ ] **S08-02 학생과 파일** — 최소 정보·접근·보존 기간·삭제·익명화 절차를 적용합니다. 키·학생 자료·답안이 번들·로그·공개 주소로 유출되지 않게 합니다.
- [ ] **S08-03 저장과 감사** — 정식 저장 구조·마이그레이션·원본 이동을 검증합니다. 승인·확정·답 정정의 담당자·버전·사유와 동시 수정 충돌을 관리합니다.
- [ ] **S08-04 실제 범위 품질** — 실사용 유형·분량에서 생성·인쇄·OMR·사람 검수 비율을 평가하고 지원 조건·미완료 항목을 확인합니다.
- [ ] **S08-05 비용과 장애** — AI 예산·후보 수·동시 요청·업로드 자원을 제한합니다. 공급자 장애·실패 기록·담당자 알림을 실제로 확인합니다.
- [ ] **S08-06 백업과 복구** — DB·문제·학습지·답안·파일을 백업하고 별도 테스트 위치에 복구해 읽습니다. 배포·되돌리는 방법과 실제 복구 시간을 기록합니다.
- [ ] **S08-07 전체 흐름** — 등록→생성→검증→승인→학생별 출력→답 확인→다음 숙제와 오류 정정을 실제 사용할 방식으로 테스트합니다.

## 간단 테스트

| 직접 해 볼 일 | 기대 결과 |
|---|---|
| WebView2의 허용되지 않은 메시지·파일 접근 시도 | 요청 차단, 공유 도입 시 다른 기관 접근도 차단 |
| 예산 초과·공급자 실패·잘못된 파일 | 제한·오류·담당자 확인, 기존 자료 보존 |
| 별도 위치에 복구해 과거 자료 열기 | 순서·정답표·학생 연결·실제 파일 복구 |
| 답 정정 뒤 다시 추천 | 중복 없이 갱신, 확정 배포본 유지 |
| 실제 분량으로 출력·판독·편성 | 지원 조건의 품질 기준 통과, 불확실 판독 검수 |

앞 단계의 대표 흐름도 한 번 실행합니다. 아래 완료 기록에 실제 테스트 결과를 남깁니다.

## 최소 범위 완료 뒤 붙일 것

- [ ] **S08-A1** 사용량에 따라 작업 큐·재시작 복구·자동 배포·관측 화면을 보강합니다.
- [ ] **S08-A2** 큰 문제 수·학생 수에서 성능·동시성·복구 목표를 다시 측정합니다.

## 준비 뒤 별도로 끝낼 한 반 파일럿

- [ ] **S08-P1** 한 반 4주에서 승인·반려 수, 교사 검수 시간, 출력 오류, OMR 수정, 개인화 사유를 주차별로 기록합니다.
- [ ] **S08-P2** 치명적인 정답·해설 오류는 유형 신규 배포 중지→영향 학습지 확인→교사 정정→명시적 재채점·재추천→같은 사례 재시험으로 수정합니다.
- [ ] **S08-P3** 수정과 재확인 뒤 지원 범위·남은 제한을 확인하고 소스·실행·운영·복구·테스트 기록을 인계합니다.

성능·정확도·복구 시간은 환경·분모와 실제 결과를 기록합니다. 목표 수치나 4주 기록만으로 학습 효과를 달성했다고 표시하지 않습니다.

## 다음 단계로 넘어가는 조건

실사용 준비 점검을 통과하고 담당자가 범위를 확인한 뒤 아래 파일럿을 진행합니다. **준비 점검 완료와 4주 파일럿 완료를 따로 기록**합니다. 09의 선택 기능은 이 단계 완료의 필수 조건이 아닙니다.

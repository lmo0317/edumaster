# 05 학생 답을 직접 넣고 채점하는 MVP

상태: 미착수 · 이전: [04 승인 문제로 학습지 출력하기](04_학습지_출력.md) · 다음: [06 학생마다 다른 보충 숙제 만들기](06_맞춤_숙제.md)

## 이번 단계에서 끝낼 것

예시 학생 2명에게 공통 학습지를 연결하고 답을 직접 입력해 학생별 채점 결과를 봅니다. 여기까지 끝내면 OMR 없이 문제 제작부터 숙제 출력·답안 확인까지 시연할 수 있습니다.

```text
예시 반 → 학생 2명 → 확정 학습지 배정 → 1~5번 답 입력 → 채점 확정 → 학생별 결과
```

## 시작 조건과 범위

- 04의 확정 학습지와 정답표가 있어야 합니다. 가상 학생 2명·반 하나·5문제·한 주차로 시작합니다.
- 학생·반·배정·응답·수정 기록만 필요한 만큼 추가합니다. 실제 학생과 외부 공유를 도입하려면 08의 관련 준비를 먼저 적용합니다.

## 최소 구현

- [ ] **S05-01 학생과 반** — 반과 학생을 만들고 고유 ID로 구분합니다. 학생 이름만으로 답안을 연결하지 않습니다.
- [ ] **S05-02 학습지 배정** — 학생에게 확정 학습지 버전을 연결하고 주차와 제출 상태를 표시합니다.
- [ ] **S05-03 직접 답 입력** — 선택 번호와 미응답을 입력합니다. 허용 범위 밖 답·잘못된 문항 수는 거부합니다.
- [ ] **S05-04 정답표 채점** — 그 학생에게 배정된 학습지 순서·버전으로 채점합니다. 미제출과 제출 후 미응답을 구분합니다.
- [ ] **S05-05 결과와 정정** — 정답 수·오답 번호·입력 답·정답을 보여 줍니다. 답 수정은 새 응답 기록으로 다시 계산합니다.
- [ ] **S05-06 중복과 저장** — 재확정 시 이중 누적을 막고 새로고침·재시작 후 같은 결과를 조회합니다.
- [ ] **S05-07 전체 MVP 시연** — 생성→검증→승인→학습지 출력→직접 답 입력→채점을 화면에서 한 번 수행해 기록합니다.

## 간단 테스트

| 직접 해 볼 일 | 기대 결과 |
|---|---|
| 민수는 모두 정답, 지우는 2개 오답 입력 | 각각 5개·3개 정답, 학생 기록 분리 |
| 한 학생 답만 정정 | 해당 학생 결과만 갱신 |
| 미제출과 빈 답 있는 제출 비교 | 미제출을 전체 오답으로 저장하지 않음 |
| 같은 입력 재확정·새로고침 | 중복 누적 없이 저장 유지 |
| 순서가 다른 학습지에 답 입력 | 해당 학습지 정답표로 채점 |

앞 단계의 대표 흐름도 한 번 실행합니다. 아래 완료 기록에 실제 테스트 결과를 남깁니다.

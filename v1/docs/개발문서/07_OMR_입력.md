# 07 OMR 한 장으로 답안 입력하기

상태: 미착수 · 이전: [06 학생마다 다른 보충 숙제 만들기](06_맞춤_숙제.md) · 다음: [08 한 반에서 쓰기 위한 준비 끝내기](08_실사용_준비.md)

## 이번 단계에서 끝낼 것

05의 답 입력 부분에 OMR 업로드를 붙이고 확정·채점·맞춤 숙제는 재사용합니다. 프로그램이 만든 5문제 답안지 한 장과 양호한 스캔으로 먼저 끝냅니다.

```text
학생용 OMR 출력 → 마킹·스캔 → 업로드 → 식별·판독 → 이미지 검수·답 수정 → 확정 → 기존 채점
```

## 시작 조건과 범위

- 05의 응답 확정과 06의 추천이 작동해야 합니다. 양식 하나·5문제·한 페이지·양호 스캔으로 시작합니다.
- 첫 버전은 사람이 전체 판독을 확인한 뒤 확정합니다. 임의 시험지·휴대폰 왜곡·자동 확정은 따로 보완합니다.

## 최소 구현

- [ ] **S07-01 작은 OMR 양식** — 고정 좌표·기준점·양식 버전을 정합니다. 학생·학습지·페이지 식별값과 서명 검사 가능한 QR을 연결하되 이름·정답은 QR에 넣지 않습니다.
- [ ] **S07-02 이미지 업로드** — 지원 형식 하나부터 받고 실제 형식·크기·손상을 검사합니다. 판독 결과와 원본을 연결해 보존합니다.
- [ ] **S07-03 식별과 좌표** — QR·서명·학습지 버전·기준점을 검사합니다. 누락·불일치·심한 기울기는 재스캔 또는 실패로 처리합니다.
- [ ] **S07-04 마킹 판독** — 미응답·복수 표시·불확실 표시를 구분합니다. 불확실 답을 하나로 추측해 자동 확정하지 않습니다.
- [ ] **S07-05 이미지 검수** — 이미지 위 판독 위치·답과 수정 폼을 보여 줍니다. 이미지 보기 종료 후 같은 검수 위치로 돌아옵니다.
- [ ] **S07-06 기존 채점 연결** — 사람 확인 후 05의 확정 기능으로 전달합니다. 원본 판독과 사람 수정 이력을 구분합니다.
- [ ] **S07-07 재입력** — 재업로드·재판독이 이중 누적하거나 사람이 고친 답을 몰래 덮지 않게 합니다.

## 간단 테스트

| 직접 해 볼 일 | 기대 결과 |
|---|---|
| 실제 출력·마킹한 답안지 스캔 | 표시 위치와 선택 답이 맞음 |
| 빈 답·두 개 표시 넣기 | 미응답·복수 표시, 사람 검토 가능 |
| 다른 학습지 QR·기준점 누락 | 잘못된 채점 대신 불일치·재스캔 안내 |
| 수정 후 같은 파일 재업로드 | 수정 기록 유지, 중복 누적 없음 |
| 직접 입력과 OMR에 같은 답 입력 | 확정 채점·맞춤 추천 결과 동일 |

앞 단계의 대표 흐름도 한 번 실행합니다. 아래 완료 기록에 실제 테스트 결과를 남깁니다.

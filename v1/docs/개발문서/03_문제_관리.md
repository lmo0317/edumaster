# 03 승인 문제를 모으고 다시 쓰기

상태: 미착수 · 이전: [02 실제 AI로 한 문제 만들기](02_실제_AI_생성.md) · 다음: [04 승인 문제로 학습지 출력하기](04_학습지_출력.md)

## 이번 단계에서 끝낼 것

승인 문제가 목록에 쌓이고 다시 열거나 학습지에 선택할 수 있는 작은 문제은행을 만듭니다. 그 뒤 풀이 단계별 생성 모드를 하나씩 추가합니다.

```text
기준 문제 목록 → 풀이·조건 편집 → 생성·검증·승인 → 승인 문제 목록 → 검색·상세·선택
```

## 시작 조건과 범위

- 02의 기준셋 평가와 화학 담당자 확인이 끝나야 합니다. 지원 유형 하나·로컬 담당자 한 명을 유지합니다.
- 문제·버전·생성·검증·승인 기록을 SQLite로 옮기되 기존 JSON 자료와 연결을 보존합니다. [AI 설계의 RAG](AI_시스템_설계.md)에 따라 승인 자료 검색을 FTS5와 연결합니다.

## 최소 구현

- [ ] **S03-01 기준 문제 목록** — 등록·목록·상세·초안 수정을 연결합니다. 필요한 화학식·수식·작은 표와 이미지부터 표현합니다.
- [ ] **S03-02 풀이 편집** — 단계 목표·입력·결과와 고정·가변 조건을 수정합니다. 없는 단계 참조·순환 의존·모순 범위는 저장하지 않습니다.
- [ ] **S03-03 승인 버전 보존** — 문제 ID와 버전 ID를 구분합니다. 승인본은 덮어쓰지 않고 수정 시 새 후보·검증·승인을 만듭니다.
- [ ] **S03-04 승인 문제은행** — 승인·권리 확인·미폐기 문제만 기본 목록과 학습지 선택 대상으로 제공합니다.
- [ ] **S03-05 기본 검색** — 제목·유형·연습 단계·난이도로 검색하고 승인 참고 자료 검색에도 연결합니다. AI에 사용한 자료 ID·버전을 보여 주고 폐기 자료는 전송 직전에 다시 차단합니다. 상세에서 돌아오면 검색 조건을 유지합니다.
- [ ] **S03-06 반려와 폐기** — 사유와 과거 기록을 보존하고 폐기 문항의 신규 사용을 막습니다.
- [ ] **S03-07 저장 형식 이동** — 형식을 바꿨다면 기존 문제·후보·승인본·검증 기록의 개수와 연결이 유지되는지 확인합니다.

## 간단 테스트

| 직접 해 볼 일 | 기대 결과 |
|---|---|
| 승인하고 목록에서 다시 열기 | 같은 승인 버전의 문제·답·해설 표시 |
| 승인본 수정하기 | 새 버전 생성, 과거 승인본 유지 |
| 미승인·권리 미확인 문제 선택 | 학습지에 사용 불가 |
| 폐기 뒤 검색·선택하기 | 신규 사용 불가, 과거 기록 유지 |
| 상세에서 검색 목록으로 돌아오기 | 필터 유지, 실제 생성 흐름도 정상 |

앞 단계의 대표 흐름도 한 번 실행합니다. 아래 완료 기록에 실제 테스트 결과를 남깁니다.

## 최소 범위 완료 뒤 붙일 것

- [ ] **S03-A1** 첫 풀이 단계만 연습하는 문제를 추가하고 뒤 단계의 추론이 필요하지 않은지 교사가 확인합니다.
- [ ] **S03-A2** 두 단계 결합형과 앞 단계 결과 제공형을 하나씩 추가합니다. 제공값은 계산과 일치하고 정답을 직접 알려 주지 않습니다.
- [ ] **S03-A3** 후보 3개 비교·부분 실패·제한 재시도·취소·작업 조회를 추가합니다. 취소가 외부 과금 취소를 보장하지 않음을 안내합니다.
- [ ] **S03-A4** 기본 개념 태그와 승인 예시 참고를 추가합니다. 미승인·권리 미확인 자료를 참고하지 않습니다.

## 다음 단계로 넘어가는 조건

최소 범위가 통과하고 승인 문제 5개가 있으면 04로 넘어갑니다. 추가 모드는 이후 하나씩 완성할 수 있습니다. 새 모드마다 02의 계산·교사 검증을 반복하고 지원 범위를 기록합니다. 선지 진단 매핑은 06에서 붙입니다.

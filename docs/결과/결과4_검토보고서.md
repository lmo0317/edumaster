## 2. 주요 지적 사항 및 오류 분석 (상세)

### 🔴 [오류 1] 전체 로직 쌍둥이 문제 표 내 기체명(화학종) 누락 (p.9)
- **위치**: 9페이지 상단 표의 세 번째 열 `반응 후 남은 A 또는 B의 질량(g)`
- **현재 표기**:
  - 실험 I: `(10)w`
  - 실험 II: `(6)w`
  - 실험 III: `(3)w`
- **문제점 분석**:
  1. 원본 문제(p.1)에서는 남은 기체가 무엇인지 **`A 10/3 w`**, **`A 2w`**, **`B w`**와 같이 화학종 기호가 명시되어 있었습니다.
  2. 쌍둥이 문제에서는 수치를 3배로 정수화하면서 `A`와 `B` 텍스트가 증발하고 괄호 `(10)w`, `(6)w`, `(3)w`로 파싱/생성되었습니다.
  3. 만약 기체를 알려주지 않는 고난도 변형이 목적이었다면, 표 머리글이 `반응 후 남은 기체의 질량`이어야 하고 발문에 "어느 기체인지는 제시하지 않았다"라는 조건이 들어가야 합니다. 하지만 머리글은 `남은 A 또는 B의 질량`인데 알맹이에서 기체명이 빠진 것은 명백한 생성 버그입니다.
- **수정 권장**:
  - 실험 I: `A 10w`
  - 실험 II: `A 6w`
  - 실험 III: `B 3w`

## 3. 문항별 세부 정합성 검증 데이터

### [STEP 1 연습 문제] (p.5)
- 반응식: $A(g) + bB(g) \rightarrow 2C(g) + 2D(g)$
- 실험 데이터:
  - I: $A=7\text{g}, B=6\text{g} \rightarrow$ 잔여 $5\text{g}$
  - II: $A=5\text{g}, B=9\text{g} \rightarrow$ 잔여 $2\text{g}$
  - III: $A=2\text{g}, B=10\text{g} \rightarrow$ 잔여 $4\text{g}$
- 검증:
  - 실험 I, II에서 $B$ 한계 반응물 $\implies$ 남은 기체 $A$.
  - 소비 질량: I ($A=2\text{g}, B=6\text{g}$), II ($A=3\text{g}, B=9\text{g}$) $\implies$ 소비 질량비 $B/A = 3$.
  - 실험 III: $A$ $2\text{g}$ 반응 시 $B$는 $6\text{g}$ 소비, 남은 $B$는 $10-6 = 4\text{g}$. 일치.
- 결과: **정답 ① (A, A, B; 3) 오류 없음.**

### [STEP 1~2 누적 연습 문제] (p.7)
- 실험 데이터:
  - I: $A=7w, B=9w \rightarrow$ 잔여 $4w$
  - II: $A=5w, B=9w \rightarrow$ 잔여 $2w$
  - III: $A=2w, B=8w \rightarrow$ 잔여 $2w$
- 검증:
  - 소비 질량비: $B/A = 3$ ($A:B = 1:3$)
  - 반응 몰수비: $n_A : n_B = 1 : b$
  - 몰질량비: $\frac{M_A}{M_B} = \frac{w_A / n_A}{w_B / n_B} = \frac{1/1}{3/b} = \frac{b}{3}$
- 결과: **정답 ① (b/3) 오류 없음.**

### [전체 로직 쌍둥이 문제] (p.9)
- 실험 데이터:
  - I: $A=15w, B=15w \rightarrow$ 잔여 `(10)w` *(A 10w로 수정 필요)*
  - II: $A=12w, B=18w \rightarrow$ 잔여 `(6)w` *(A 6w로 수정 필요)*
  - III: $A=6w, B=21w \rightarrow$ 잔여 `(3)w` *(B 3w로 수정 필요)*
- 검증:
  - 원본 수치의 정확히 3배 배율 적용.
  - 몰분율과 상댓값($18, 20, x=15$), 계수($b=3$), 몰질량비는 원본과 100% 동일.
- 결과: **수학적/화학적 계산 자체는 유효하나 표 표기 누락 수정 필수.**

# 유사 킬러 화학 문제 샘플

## 선택한 실제 기출

- **자료:** 2024학년도 7월 고3 전국연합학력평가 화학Ⅰ 19번
- **유형:** 화학 반응식의 양적 관계
- **선정 이유:** 두 실험의 질량과 반응 후 기체 밀도비에서 물질량 관계를 구하고, 이를 분자량비로 연결한다. 기존 `02페이지_킬러문제와해설.jpeg`의 반응량·양적 관계 풀이 로직과 가깝다.
- **난이도 근거:** 공개된 오답률 순위에서 화학Ⅰ 오답률 2위 문항이다.

## 앱 테스트용 독자 작성 샘플

1. `샘플자료/06_유사킬러_화학반응_문제.png`를 **문제 이미지**에 넣는다.
2. `샘플자료/07_유사킬러_화학반응_정답해설.png`를 **풀이 이미지**에 넣는다.
3. 생성 목표는 표면 문장을 흉내 내는 것이 아니라 다음 네 단계를 보존하는 것이다.
   - 기준 물질량 두기
   - 두 실험의 반응 후 물질량 정리
   - 밀도비로 미지 물질량 관계 계산
   - 반응식의 질량 보존으로 분자량비와 정답 계산

이 샘플은 공식 19번의 학습 구조만 참고해 수치, 보기, 문장과 정답을 새로 작성했다. 정답은 **④ 9/2**이다.

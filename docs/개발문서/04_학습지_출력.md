# 04 승인 문제로 학습지 출력하기

상태: 미착수 · 이전: [03 승인 문제를 모으고 다시 쓰기](03_문제_관리.md) · 다음: [05 학생 답을 직접 넣고 채점하는 MVP](05_수동_채점_MVP.md)

## 이번 단계에서 끝낼 것

승인 문제 5개를 골라 순서를 확인하고 학습지를 확정한 뒤 문제 PDF와 정답·해설 PDF를 출력합니다. 공통 학습지 하나로 끝냅니다.

```text
5문제 선택 → 순서 변경 → 미리보기 → 학습지 버전 확정 → 문제지 PDF / 정답·해설 PDF
```

## 시작 조건과 범위

- 03에 출력할 승인 문제 5개가 있어야 합니다. 예시 반의 공통 학습지 하나·A4·수동 선택으로 시작합니다.
- 학생별 편성·OMR·정식 PDF 작업 큐보다 실제 파일을 열고 인쇄하는 흐름을 먼저 완성합니다.

## 최소 구현

- [ ] **S04-01 문제 선택** — 승인·권리 확인·미폐기 문항만 선택합니다. 문항 수와 중복을 확정 전에 검사합니다.
- [ ] **S04-02 순서와 미리보기** — 빼기·교체·순서 변경을 제공합니다. 미리보기 번호와 실제 출력 번호를 일치시킵니다.
- [ ] **S04-03 확정 버전 고정** — 학습지 ID·버전, 문제 버전·순서·정답표를 복사해 보존합니다. 나중에 문제를 수정해도 이 학습지는 바뀌지 않습니다.
- [ ] **S04-04 분리 PDF** — 문제지와 정답·해설지를 별도 파일로 만듭니다. 문제지에 정답·해설이 노출되지 않게 합니다.
- [ ] **S04-05 출력 품질** — 한글·필요한 화학식·표·이미지를 표현하고 문항·보기 잘림·겹침·비정상 페이지 나눔을 막습니다.
- [ ] **S04-06 다운로드 상태** — 필수 파일 모두 준비되어야 출력 준비 완료입니다. 생성 실패와 재시도를 안내합니다.

## 간단 테스트

| 직접 해 볼 일 | 기대 결과 |
|---|---|
| 순서를 바꾸고 5문제 확정 | 미리보기·PDF·정답표 순서 동일 |
| 문제와 해설 PDF 각각 열기 | 문제지에 답 없음, 해설 번호 일치 |
| 기준 문제 수정 뒤 과거 학습지 열기 | 과거 본문·순서·정답표·파일 유지 |
| 표·긴 보기가 있는 문제 출력 | 모든 페이지에 잘림·겹침 없음 |
| PDF 하나의 생성 실패 | 전체 준비 완료 아님, 같은 확정본 재시도 가능 |

앞 단계의 대표 흐름도 한 번 실행합니다. 아래 완료 기록에 실제 테스트 결과를 남깁니다.

## 최소 범위 완료 뒤 붙일 것

- [ ] **S04-A1** 문제 수를 10개·20개로 늘리고 긴 문항의 페이지 나눔을 보완합니다.
- [ ] **S04-A2** 정답지 단독 출력을 추가하고 정정은 새 학습지 버전으로 만듭니다.
- [ ] **S04-A3** 문제 계열별 사용 횟수와 학생별 최근 출제를 기록합니다.

## 다음 단계로 넘어가는 조건

최소 범위와 PDF 모든 페이지 확인이 통과하고 A4 한 부를 실제 인쇄하면 05로 넘어갑니다. PDF 생성 로그만으로 인쇄 품질을 통과 처리하지 않습니다. 확정 버전의 순서·정답표 고정이 필수입니다.

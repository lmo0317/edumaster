# 09 필요한 기능을 하나씩 넓히기

상태: 선택 전 · 기준: [08 실사용 준비](08_실사용_준비.md) · [전체 진행 안내](README.md)

이 파일 전체를 한 번에 구현하지 않습니다. 필요한 **확장 묶음 하나만 선택하고 작은 구현·테스트·기록을 끝낸 뒤** 다음 묶음으로 넘어갑니다. 08 완료의 필수 선행도 아닙니다.

## 확장 A 가정의 모순으로 푸는 문제

원본의 “A가 다 반응했다고 가정하면 모순이므로 B가 다 반응했다” 같은 추론을 지원합니다. 02의 단순 반응량 문제가 이 기능까지 구현한 것으로 표시하지 않습니다.

- [ ] **S09-A1** 승인 문제 한 개의 두 가정·조건·중간값을 구조화합니다.
- [ ] **S09-A2** 두 가정을 독립 계산하고 의도한 한쪽만 성립하는지 검사합니다.
- [ ] **S09-A3** 같은 방향·반전 방향 후보 한 개씩을 생성해 단계형 연습과 검증·승인으로 연결합니다.
- 테스트: 한쪽 성립, 양쪽 성립, 양쪽 모순. 뒤의 두 경우는 실패해야 합니다.
- 완료: 좁은 사례를 재현한 뒤 기준셋을 넓혀 평가하고 화학 담당자가 지원 범위를 확인합니다.

## 확장 B 분자 구조와 결합각

- [ ] **S09-B1** 지원 분자·예외와 화학 담당자가 확인한 기준 지식을 정합니다.
- [ ] **S09-B2** 분자 하나의 구조 그림과 모양·각도 관련 보기 판정을 화면과 PDF에 연결합니다.
- [ ] **S09-B3** 전자수·전하·구조·선지 조합을 검증하고 범위 밖 분자는 미지원으로 처리합니다.
- 테스트: 정상 구조, 잘못된 전자수·전하, 미지원 분자. 오류·미지원 후보는 승인 불가입니다.
- 완료: 별도 기준셋·생성 평가를 통과한 지원 목록만 엽니다. 그림이 나온 것만으로 전체 단원 완료는 아닙니다.

## 확장 C 개인화 판단 보완

- [ ] **S09-C1** 06의 보완 중 선지 진단·연속 성공·복습·새 변형 연결 한 가지를 선택합니다.
- [ ] **S09-C2** 학생 한 명의 4주 예시로 새 규칙·선택 이유를 확인합니다.
- [ ] **S09-C3** 정정 재계산·정책 변경·회복 뒤 재오답을 검사합니다.
- 테스트: 미제출·모호한 오답·2주 성공·재오답. 과잉 단정·중복 누적·과거 확정본 변경이 없어야 합니다.
- 완료: 선택한 규칙의 재현과 기존 흐름 유지. 학습 효과 검증은 실제 운영 자료로 별도 수행합니다.

## 확장 D 운영 규모와 편의

- [ ] **S09-D1** 실제 불편 하나를 선택합니다. 예: 일괄 등록·고급 검색·저장된 검색·다기관·SSO·대량 출력.
- [ ] **S09-D2** 작은 자료 묶음으로 화면과 처리 흐름부터 연결합니다.
- [ ] **S09-D3** 필요한 작업 큐·참고 검색·동시성·비용 제한을 붙이고 기존 자료 이동·재시작을 확인합니다.
- 테스트: 정상·일부 실패·동일 입력 재실행·권한·해당 규모 처리 시간.
- 완료: 선택한 불편 해결과 이전 대표 흐름 유지. 다음 편의는 그 뒤에 시작합니다.

## 기록과 범위

확장 ID, 해결할 불편, 눈으로 볼 결과, 최소 체크리스트, 테스트 결과, 지원 범위와 다음 행동을 기록합니다. 한 묶음이 커지면 `09A_가정모순.md`처럼 독립 문서로 꺼내고 여기는 링크만 남깁니다.

별도 모델 훈련·임의 교재 완전 자동 인식·손글씨 서술형 채점·학생용 앱·다른 과목은 기본 MVP가 아닙니다. 필요할 때 새 범위를 정합니다.
